- Implemented: extended `ci.yml` with a `publish` job (build local → Trivy scan →

  `.trivyignore`, and bumped the coverage ratchet floor to 0.87.
- Ran the code-reviewer agent before committing (CLAUDE.md gate) — it caught a **real
  bug**: `type=raw,value=latest,enable={{is_default_branch}}` is always false in this job

  plain push to `main` would have shipped an empty tag list and failed the push step
  outright. Fixed with an explicit `enable=${{ github.ref == 'refs/heads/main' }}`. Also
  swapped the Trivy scan target from `build-push-action`'s `imageid` output (unconfirmed
  pattern) to the first computed tag (documented pattern). Full writeup in
  `decisions/0018-docker-publish-trivy-gate-issue-34.md`.

  ("feat(ci): publish versioned Docker image with vulnerability scanning", `Closes #34`).
